Rabbit Ears

Rabbit Ears is a self-hosted media server for one household's movies, TV shows, music and YouTube downloads. The household runs the server on its own Mac. The server reads the household's own media folders, adds titles, artwork and descriptions, and streams to the Rabbit Ears apps for the web, Mac, iPhone, Apple TV, Android and Roku.

Each adult has their own sign-in, watch history and playlists. Kids get profiles filtered by content rating or by a list a parent picks. The server picks the best way to play each file on each device, so a movie plays as it is where it can, and is converted where it must be. Stations play a playlist as a channel on a schedule.

The apps contain no media and no account. To use one you need a Rabbit Ears server, run by you or by your household, and an account on it. Open the app, enter your server's address, and sign in. On Roku and Apple TV you can also show a code on the TV and approve it from the web client.

Rabbit Ears is free software under the MIT license, published by Legitimate Enterprises. Legitimate Enterprises runs no Rabbit Ears server and sees none of your data.
